# Results: Milestones 2-4

Generated by `demo_milestones_2_3_4.py`; raw numbers also saved to
`docs/milestone_results.json`. Full reproduction instructions at the
bottom.

## Important caveat, up front

The public benchmark datasets this project targets (Cora, CiteSeer,
PubMed, MUTAG) could not be downloaded from the sandboxed environment this
work was built in - see `utils/graph_builder.py`'s module docstring for
why. Every number below is on a **synthetic dataset built to share the
real ones' key structural properties** (homophily and sparse categorical
features for the citation-graph task; a labelled structural motif for the
graph-classification task) - not the literal public benchmarks. The
dataset loaders for the real data are written and included
(`utils/graph_builder.py: load_cora`, `load_citeseer`, `load_pubmed`,
`load_mutag`), and running them (from a machine with normal internet
access) is the natural next step before quoting these numbers as "Cora
accuracy" to anyone.

## Node classification (Milestone 2 + 3)

500-node synthetic citation graph, 6 classes, 100 input features,
2-layer QuantumGNN (100 -> 32 -> 6), Adam optimiser, 150 epochs,
Planetoid-style split (20 labelled nodes per class for training, 20% of
the remainder for validation, the rest for test).

| | value |
|---|---|
| Final train accuracy | 100.0% |
| Final validation accuracy | 65.8% |
| **Test accuracy** | **74.3%** |
| Random-chance baseline | 16.7% |

Train accuracy reaching 100% with test accuracy well below that is the
expected shape for this kind of very-few-labels split (only 120 of 500
nodes are ever labelled) - the gap shows the model memorising the small
training set, while still generalising far above chance via the message
passing. See `docs/milestone2_node_classification.png` for the loss/accuracy
curves.

## Graph classification (Milestone 3)

200 synthetic MUTAG-shaped graphs (10-25 nodes each, 7 categorical node
labels), 150/50 train/test split, 2-layer GraphClassifier with mean
readout, Adam optimiser, 40 epochs.

| | value |
|---|---|
| Final train accuracy | 98.7% |
| **Test accuracy** | **98.0%** |
| Random-chance baseline | 50.0% |

See `docs/milestone3_graph_classification.png`.

## Milestone 4: interference kernels

`docs/milestone4_interference_kernels.png` plots all three kernels
(cosine, squared-cosine, Gaussian) as a function of phase difference on
one axis, showing the qualitative difference the architecture doc
(`docs/ARCHITECTURE.md`, section 5) describes: cosine and squared-cosine
are periodic, Gaussian is not; squared-cosine and Gaussian are both
non-negative, plain cosine is not.

## Milestone 4: decoherence-inspired damping

Same synthetic citation-graph setup as above (300 nodes, 5 classes, 100
epochs), sweeping the decoherence rate:

| decoherence_rate | test accuracy |
|---|---|
| 0.0 (off) | 71.3% |
| 0.15 | 73.1% |
| 0.5 | 73.8% |

On this particular synthetic dataset, adding decoherence gave a small,
consistent improvement rather than a dramatic one. Worth being honest
about rather than oversold: this is one dataset, one architecture, one
seed - it's a promising direction (the trend is monotonic and consistent),
not yet a validated result. A proper ablation (multiple seeds, a
statistical significance test, and - critically - the real datasets once
reachable) is the natural Milestone 5 follow-up.
